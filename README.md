# ווידג'ט נגישות לשופיפיי — IS 5568 / WCAG 2.0 AA

> פלאגין נגישות חינמי ופתוח לאתרי שופיפיי, עומד בתקן הישראלי 5568 ובתקן WCAG 2.0 AA הבינלאומי.

---

## מה זה ווידג'ט נגישות?

חוק שוויון זכויות לאנשים עם מוגבלות (1998) מחייב כל עסק עם מחזור מעל ₪300,000 לאפשר גישה לאתר שלו לאנשים עם מוגבלויות שונות: עיוורון, לקות ראייה, דיסלקציה, מוגבלות מוטורית ועוד.

הפלאגין הזה מוסיף כפתור "נגישות" לאתר שלך שפותח תפריט עם כל הכלים הנדרשים.

## תקן ישראלי 5568 (IS 5568)

### מה הוא מחייב?
- עמידה ב-**WCAG 2.0 רמה AA** בכל עמודי האתר
- פרסום **הצהרת נגישות** באתר
- מינוי **רכז נגישות** ופרטי יצירת קשר
- תגמול עד **₪50,000** בגין אי-עמידה בתקן

### מי חייב?
- גופים ממשלתיים: חובה מוחלטת
- עסקים עם מחזור מעל ₪300,000: חובה
- עסקים עם מחזור מתחת ל-₪100,000: פטור

---

## מה הפלאגין הזה *אינו* מחליף?

הווידג'ט מוסיף **שכבת נגישות** על גבי האתר הקיים. הוא **לא** מתקן בעיות עמוקות:

- תמונות ללא תיאורי alt — צריך להוסיף בשופיפיי
- טפסים ללא תוויות — צריך לתקן בקוד
- היעדר ניווט מלא במקלדת — תלוי ב-theme
- מבנה כותרות לא תקין — תלוי בתוכן

לנגישות מלאה, מומלץ גם לבצע בדיקת WCAG מקיפה על ידי מומחה.

## הגדרות מהירות

בתוך הקובץ `accessibility-widget.js`, בחלק `CONFIG`:

```javascript
var CONFIG = {
  storageKey:   'a11y_settings_v1',
  statementUrl: '/pages/hagashat-negishut', // ← שנה לכתובת עמוד הנגישות שלך
  widgetTitle:  'כלי נגישות',               // ← שם הכפתור
  openBtnLabel: 'פתח / סגור כלי נגישות',   // ← תיאור למסך קורא
  position:     'bottom-left',              // ← 'bottom-left' | 'bottom-right'
};
```
